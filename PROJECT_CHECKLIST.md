## ⚠️ Known Limitations (By Design)

These are intentional placeholders for future development:

- [ ] API calls return dummy data (not connected to backend)
- [ ] Authentication is simulated (accepts any credentials)
- [ ] Payments don't process real transactions
- [ ] QR codes are generated but not validated
- [ ] NFC features are placeholders
- [ ] Push notifications not implemented
- [ ] Image assets are external URLs
- [ ] No persistent storage (data resets on reload)

**These are expected and will be addressed in the next phase!**
