# Assets Directory

This directory should contain the following image assets for the Sonnix app:

## Required Files

1. **icon.png** (1024x1024)
   - App icon displayed on home screen
   - Should feature the Sonnix logo with purple (#7B2CBF) theme

2. **splash.png** (1242x2436 recommended)
   - Splash screen shown when app launches
   - Dark background (#0D0D0D) with Sonnix branding

3. **adaptive-icon.png** (1024x1024)
   - Android adaptive icon foreground
   - Transparent background, centered icon

4. **favicon.png** (48x48)
   - Web favicon for PWA version

## Temporary Solution

For development, Expo will use default placeholder icons. 
Replace these with actual branded assets before production release.

## Design Guidelines

- Primary Color: #7B2CBF (Purple)
- Background: #0D0D0D (Dark)
- Icon should be recognizable and match app branding
- Use simple, bold designs that work at small sizes
