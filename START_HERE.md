## ⚡ Quick Commands

```bash
# Install everything
npm install

# Start development server

# Start with cache cleared
npm start -- --clear

# Run on iOS simulator (Mac only)
npm run ios

# Run on Android emulator
npm run android

# Run in web browser
npm run web
```

## 🐛 Having Issues?

### Can't install packages?
```bash
rm -rf node_modules
npm install
```

### App won't start?
```bash
npm start -- --clear
```

### Can't connect to Expo Go?
```bash
npm start -- --tunnel
```

### Need more help?
- Check [SETUP.md](SETUP.md) for detailed troubleshooting
- Review [Expo docs](https://docs.expo.dev/)
- Check terminal for error messages
